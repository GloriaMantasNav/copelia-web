# Copelia — página web

Sitio web estático para presentar el grupo musical. Incluye presentación, agrupaciones, descarga de cinco repertorios en PDF y sección de contacto. Está adaptado a móviles y escritorio.

## Abrir

Abre `index.html` con un navegador. No necesita instalar dependencias ni ejecutar un servidor.

## Recursos y límites actuales

- Las imágenes y el repertorio están en `assets/` y se cargan con rutas relativas, así que la carpeta se puede mover completa.
- El apartado de repertorio ofrece descargas de Songs, Flamenco, Bandas sonoras, Canciones y Clásico.
- No se proporcionaron grabaciones de audio; la página dirige a los cinco PDF del repertorio en vez de incluir controles de reproducción sin sonido.
- El formulario valida los campos y prepara un correo dirigido a `copeliamusica@gmail.com` en la aplicación de correo predeterminada. La persona debe confirmar el envío allí.
- El pie usa la nueva foto con una capa verde semitransparente, iconos blancos enlazados a Instagram, teléfono, correo y Bodas.net, y el logo blanco centrado.
