# Copelia — página web

Sitio web estático para presentar el grupo musical. Incluye presentación, agrupaciones, descarga del repertorio en PDF y sección de contacto. Está adaptado a móviles y escritorio.

## Abrir

Abre `index.html` con un navegador. No necesita instalar dependencias ni ejecutar un servidor.

## Recursos y límites actuales

- Las imágenes y el repertorio están en `assets/` y se cargan con rutas relativas, así que la carpeta se puede mover completa.
- No se proporcionaron grabaciones de audio; la página dirige al PDF del repertorio en vez de incluir controles de reproducción sin sonido.
- El formulario valida los campos y prepara un correo dirigido a `copeliamusica@gmail.com` en la aplicación de correo predeterminada. La persona debe confirmar el envío allí.
- La imagen de pie conserva los iconos gráficos originales; no se añadieron enlaces a perfiles porque no se proporcionaron sus direcciones.
